## 仍未关闭的验收项和已知限制

- `fingerprint-chromium` 当前只有适配器、配置 schema 和未配置 manifest；没有已确认来源、许可证、下载 URL 和 SHA-256，因此不能宣称可下载或分发该内核。标准 Chromium 只探测用户本机已有且用户有权使用的 Chromium/Chrome/Edge。
- 已完成标准 Chromium 的打包 Worker CDP smoke；使用专用测试代理完成 HTTP、HTTPS、SOCKS5 认证矩阵仍待后续验收。
- 桌面 UI 自动化、异常退出的跨平台手动矩阵、低磁盘和下载中断测试尚未全部自动化覆盖。
- 本机 macOS arm64 的 `electron-builder --dir` 曾在 packaging 阶段长时间无输出而中止；三个目标平台的 CI Release 构建均已通过，因此 CI 是本轮 macOS 产物证据来源。
- Release 产物未签名或公证，首次启动可能需要按系统提示手动放行。
- v0.1 不包含团队 API、PostgreSQL、WebUI、工作流、LangChain/LangGraph、RAG、远程执行、备份同步或完整指纹隐身承诺。

## 2026-09-22 主体内容统一重构

- 根据 GitHub 上 shadcn-admin、new-api、Simprint、CloakBrowser Manager 和 vue-vben-admin 的源码研究，重新设计业务页面主体，不再使用每个页面独立的顶部标题/描述和多层 Card 边框。
- 环境与代理统一为“数量/当前选择 + 搜索/筛选/创建工具栏 → 单一数据表面 → 选中环境的底部动作条”；空态仍使用 `Empty`，行操作仍使用 `DropdownMenu`。
