## 当前限制

实现必须严格遵循 `docs/versions/v0.1-execution-r6.md`；在用户最终验收和所有发布门禁通过前，不得创建正式 Release tag 或推送 GitHub Release。

- v0.1 使用 Electron/Node `node:sqlite` 运行时，详见 [ADR 0001](../adr/0001-local-sqlite-runtime.md)；Node 22 下测试会显示实验性警告。
- v0.1 使用 shadcn/ui `base-nova` 与 Base UI；Radix UI 不再作为桌面 UI primitive。
- fingerprint-chromium 只注册适配器和专属参数 schema，尚未配置可分发的内核下载地址、许可证和哈希。
- 标准 Chromium 只探测用户本机 Chrome、Edge 或 Chromium，不随安装包分发专有浏览器二进制。
- 当前本机已完成 Windows x64 未压缩目录构建和启动检查；macOS 产物尚未在本机验证。
- v0.1 不包含团队 API、PostgreSQL、WebUI、工作流、LangChain/LangGraph、RAG、远程执行和备份同步。
