# ContextWeave v0.2.7 · 个人工作空间体验收敛

本版面向日常多环境用户，减少开发诊断对普通设置的干扰，清理未使用的界面依赖；保留现有功能和数据保护，不扩张旧版本线。

## 主要变化

- 截图预算与已登记截图移入默认折叠的“高级诊断”，首次展开后才读取数据。收起时不会丢弃编辑、停止任务或删除产物。
- 历史清理和待核对操作优先展示结果与处理提示，请求/批次编号收进诊断详情；危险操作确认与未知结果保护保持不变。
- 清理没有业务入口的 UI 组件和直接依赖，保留主题定制、环境组织、空间隔离及后台批任务。
- 延续已提交的内核提供方身份隔离，旧环境、内核 ID、profile 和 seed 不迁移；待审核的新提供方仍不可安装或运行。
- 后续发布采用统一中文说明；去重主分支重复源码检查，保留三平台原生与安装包验证。

## 升级与兼容

- 本版由 v0.2.6 升级，应用版本统一为 0.2.7，SQLite schema 仍为 13；不新增数据迁移，不重建环境、代理凭据或浏览器资料目录。
- 截图登记、预算和未知预留继续兼容保存。高级诊断只是界面调整，不自动删除文件、释放未知预留或重发命令。
- 安装前停止运行中的环境并退出应用；重要数据应保留独立副本。本版不提供完整备份/恢复产品，也不承诺向旧 schema 降级。

| 系统                | 安装包                                                                                       |
| ------------------- | -------------------------------------------------------------------------------------------- |
| Windows x64         | `ContextWeave-0.2.7-win-x64-setup.exe`；免安装版为 `ContextWeave-0.2.7-win-x64-portable.exe` |
| macOS Apple Silicon | `ContextWeave-0.2.7-mac-arm64.dmg` 或对应 ZIP                                                |
| macOS Intel         | `ContextWeave-0.2.7-mac-x64.dmg` 或对应 ZIP；管理端支持不等于 Intel 指纹内核已准入           |

请使用本 Release 附件及对应的 `SHA256SUMS-<平台>.txt` 核验下载；安装包尚无发行身份签名/macOS 公证，系统可能显示安全提示。不要全局关闭系统安全保护。

## 验证范围

- 发布门禁覆盖格式、lint、类型检查、单元/契约测试，以及 Windows x64、macOS x64/arm64 的桌面生命周期与实际打包程序检查。
- 包体检查包括运行依赖、ASAR 完整性、Electron Fuses、平台架构和附件 SHA-256。支持平台的既有指纹内核另执行原生生命周期验证；这不代表 Intel 候选通过验收。
- 本版交互回归覆盖诊断按需加载、折叠保留编辑状态、历史清理结果和诊断详情；安全、预算与命令幂等断言未放宽。具体执行结果见本 tag 的 Release 工作流及版本台账 17.32；自动验证不代替全部设备的人工验收。

## 已知限制

- 项目根许可证仍待维护者最终决定；第三方组件及浏览器内核继续受各自许可约束，本版不宣称完成全部许可准入。

- Intel Mac 的合格指纹提供方与三平台正式准入仍属于 v0.3.0，不能以标准 Chromium 或待审核包替代验收；现有上游的源码对应缺口仍保留。
- 截图统计不是全盘磁盘占用；未知预留仍保守保留，暂未提供截图显式清理。不要手动修改数据库来解除限制。
- 原生 Cookie 重开保留曾出现未复现的失败，诊断与后续通过记录保留，不宣称根因已修复。
- 当前尚未交付完整备份、Local API/CLI/MCP 或团队协作，不因本次收敛宣称个人稳定版完成。
