# ContextWeave v0.3.0 · 多平台内核与个人工作流

## 主要变化

- 增加固定来源、按发行方和平台隔离的内核准入：Windows x64、macOS Intel 和 macOS Apple Silicon 使用各自核验的发行包记录。
- 安装内核时可以填写可选的自定义名称；名称只影响显示，不改变内核 ID、版本、来源或环境绑定，安装后也可重命名。
- 下载和安装过程校验发行包来源、平台/架构、归档路径与 SHA-256；支持随发行物提供的 `SHA256SUMS` 校验文件。
- 安装完成后执行离线基础能力检测，并在内核详情中显示证据时间、版本和重新验证入口。代理和 WebRTC 仍不会被错误标记为已验证。
- 完善个人工作流：书签行内编辑、拖拽排序和启动开关；日志日期范围筛选；标签和内核多选删除；统一历史表格及右侧固定操作列；友好的 Toast 失败提示。
- 修复本地存储复制数据地址、代理认证启动、标签页恢复、控制通道并发和浏览器状态恢复等问题。

## 升级与兼容

- 本版由 v0.2.7 升级，工作区包版本统一为 0.3.0；既有环境、内核 ID、版本、代理配置、凭据和浏览器资料目录保持不变。
- 本版不要求重建环境或迁移浏览器 profile。升级前仍建议停止运行中的环境并保留独立备份；不支持向旧 schema 降级。
- 自定义内核名称是显示元数据；未填写名称的既有内核继续使用默认名称。验证失败不会删除已安装的内核或安装包。

## 下载与安装

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | `ContextWeave-0.3.0-win-x64-setup.exe` 或 `ContextWeave-0.3.0-win-x64-portable.exe` |
| macOS Apple Silicon | `ContextWeave-0.3.0-mac-arm64.dmg` 或对应 ZIP |
| macOS Intel | `ContextWeave-0.3.0-mac-x64.dmg` 或对应 ZIP |

请使用本 Release 附件及对应平台的 `SHA256SUMS-<平台>.txt` 核验下载。当前安装包没有代码签名或 macOS 公证，系统可能显示安全提示；不要通过关闭系统安全保护来安装。

## 验证范围

- 发布门禁包含格式、lint、TypeScript 类型检查、workspace 单元/契约测试、Electron 构建、桌面生命周期、用户工作流、应用更新和打包文件检查。
- 三个平台均执行 source-reviewed 内核的安装、启动、停止、重启和删除保护验收；本机之外的平台结论以对应 GitHub Actions runner 的结果为准。
- 离线能力验证覆盖 CDP、页面截图、元素截图、文件上传、User-Agent 和时区；验证记录包含实际版本、时间和证据。自动化验收不等同于所有设备的人工验收。

## 已知限制

- 代理和 WebRTC 在能力页仍为未验证；本版本不宣称指纹效果、防关联分数、提供方认证或绕过网站风控。
- 内核验证是离线基础能力检查，不是对第三方网站、账号、验证码或平台策略的兼容承诺。
- 安装包当前没有代码签名或 macOS 公证；未提供 Linux 安装包，也未宣称 Windows/macOS 之外的平台通过验收。
- 项目仍未交付完整备份/恢复产品、Local API/CLI/MCP 或团队协作能力；发布 smoke 不替代用户对真实网站和真实账号的人工验收。

## 后续计划

- v0.3.0 之后不自动开始新的版本开发；备份、扩展、Local API/CLI/MCP、团队工作空间和更复杂的自动化能力需维护者另行确认范围与验收门槛。
